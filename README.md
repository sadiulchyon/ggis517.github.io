# GGIS 517 Course Work Materials

This repository contains course work materials and projects for GGIS 517 (Geographic Information Systems). It includes interactive web-based mapping visualizations and geospatial analysis projects.

## Projects Overview

### 1. **HeatMap Visualization**
- **File**: `HeatMap.html`
- **Description**: Interactive heat map visualization built with Leaflet.js, displaying geographic data with heat distribution patterns
- **Technologies**: Leaflet, JavaScript, HTML5
- **Features**: Dynamic heat mapping, interactive layers, custom styling

### 2. **Lab 3 & Lab 4 - Interactive Maps**
- **Files**: `LAB3.html`, `LAB4_saadi.html`
- **Description**: Geographic mapping exercises using Leaflet.js with university and location-based data visualization
- **Technologies**: Leaflet.js, L3.js, Uni.js data libraries, jQuery
- **Features**: Interactive map overlays, data-driven styling, information boxes

### 3. **Choropleth & 2D Density Maps**
- **Directory**: `Choropleth_2Ddensity/`
- **Description**: Collection of thematic mapping visualizations including:
  - **Choropleth Maps** (Map 1 & Map 2): Color-coded region visualization
  - **2D Histogram Contour Plot**: Density distribution visualization with histogram subplots
- **Technologies**: D3.js, JavaScript, HTML5, CSS
- **Features**: Choropleth color schemes, contour plotting, histogram integration

### 4. **GGIS 517 Final Project**
- **Directory**: `GGIS 517 FInal project/`
- **Description**: Comprehensive final project featuring an interactive geospatial visualization dashboard
- **Technologies**: Leaflet.js, QGIS2Web, GeoJSON, JavaScript, CSS
- **Features**:
  - Interactive web map with multiple data layers
  - Custom legend and styling
  - Geographic feature highlighting
  - Responsive design with font awesome icons
  - Data-driven choropleth coloring

## Technologies Used
- **Web Mapping**: Leaflet.js, QGIS2Web
- **Visualization**: D3.js, HTML5 Canvas
- **Data Formats**: GeoJSON, CSV
- **Styling**: CSS3, Font Awesome Icons
- **Interactivity**: JavaScript, jQuery

## How to Use
1. Clone the repository
2. Open any `.html` file directly in a web browser to view the visualizations
3. Projects are interactive - explore the maps and features by clicking and hovering over elements
